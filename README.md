Python exercises from **Fundamentals of Programming** (CCCS 102), a first-year BS Computer Science course at Camarines Sur Polytechnic Colleges: individual exercises on the core topics. The course's group final project, a calculator with a text corrector, lives in its own repository: **`jejemon-text-corrector`**.

## Projects

| Project | Dates | Description |
|---|---|---|
| [python-fundamentals](python-fundamentals/) | Sep 2023 – May 2024 | Exercises on operators, classes, strings, lists, tuples, sets, dictionaries and file handling, with sample output and notes on what I learned |

## Timeline

The work covers **September 2023 to May 2024** (dates are taken from the file timestamps). The dates for each exercise are listed in [python-fundamentals](python-fundamentals/#contents).

## Running the code

You need Python 3 and nothing else. Open a terminal in the folder of the script and run:

```bash
python3 <script>.py
```

Some scripts read other files from the same folder, so run them from inside their own folder. The project README has the details: [Python Fundamentals](python-fundamentals/README.md).
